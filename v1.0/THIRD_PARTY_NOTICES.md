# 第三方许可与权重来源

本仓库**不含任何模型权重与训练数据**。下面写清每个引擎的代码许可、权重来源、以及为什么权重不进来。

## 引擎

| 引擎 | 代码许可 | 权重 / 数据 | 能不能分发 |
|---|---|---|---|
| **ROSVOT** | MIT | 权重见其 release 页 | 代码可以；权重要看 release 里写的条款 |
| **DiffSinger** | Apache-2.0 | 声库（数据集）许可各自看，常见 CC-BY / CC-BY-NC | 代码可以；声库多数不可商用 |
| **RVC** | MIT | 自训权重可以分发；用别人的训练集则受数据集许可约束 | 自训可以 |
| **GAME** | MIT（代码） | 官方权重 **CC BY-NC-SA**（非商用、相同方式共享） | 不可商用、不可再分发 |
| **SoulX-Singer** | Apache-2.0 | 权重与训练数据另有条款 | 代码可以；权重不下、不镜像 |
| **ヒツボク・クミ（UTAU 音源）** | 库内 license.md | 不随本仓库分发 | 自己下 |
| **basic-pitch（nmp.onnx，听的转录模型）** | Apache-2.0 | ICASSP 2022 预训练模型，0.2MB，随仓库分发 | 可以 |

## 我们自己的取舍

1. **代码进仓库，权重不进**。理由是许可，不是技术洁癖：权重许可大多写着「仅研究 / 不可再分发」，打包分发会把这些风险一起给出去。
2. **训练数据的血统要写清**。同一个模型，代码是 MIT 不代表权重能商用——权重是训练出来的，训练数据的许可会跟上来。
3. **不镜像、不打包、不转存**。仓库里只放下载地址和校验方式，见 `docs/MODELS.md`。
4. 研究用途的模型（例如 GAME）放在隔离区，不进主流程。
