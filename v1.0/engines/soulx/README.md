# SoulX-Singer（零样本歌声合成）

**代码 Apache-2.0；权重与训练数据另有条款，不随仓库分发。**

## 这条路的特别之处

零样本：给一段**参考音色**（几秒到几十秒的 wav）+ 一份谱，直接唱出那个音色。
不需要先训一个模型，也不需要先有一个「像谁」的转换模型。

```
参考音色.wav + score.json → SoulX-Singer → 那个音色唱的 wav
```

## 我们的实测

- 704M 参数、fp16，12G 卡上峰值显存约 4.3G。
- 按谱唱，音高误差中位 **-1 音分**（这一点很好）。
- 给参考音色之后，音高会被参考音带跑一点：中位 **+9 音分**（能听出来但不算跑调）。
- 按谱 RTF 约 0.27（三分钟的歌约 50 秒）。

## 一个真实踩过的坑

`cli` 的 `--control` **默认是 `melody`**，而官方的 `infer.sh` 没传 `control=score`。
照官方脚本跑，出来的是「按旋律自由唱」而不是「按谱唱」——音高全不对。

**要按谱唱就必须显式传 `--control score`。** 这个坑值得写进任何一份使用说明。

## 参考音色怎么选

- 用**唱歌**的片段当参考，比用说话的好。
- 说话语料当参考是反例：音高会被拽向说话的语调。
- 参考片段的响度先做一次归一化，否则结果响度会跟着参考跑。
