# ROSVOT（扒谱）

**代码 MIT；权重不在本仓库。**

## 它是这一整条流程的第一步

```
音频 → ROSVOT → 音符谱（midi + 时值 + 音高走向）→ DiffSinger 唱
```

扒谱的质量决定后面所有环节的上限：谱上少一个音，唱出来就少一个字。

## 为什么要单独挑它

- MIT，能对外发。
- 输出是「音高 + 时间」而不是「一段音频」，所以每一步都能回查、能改。
- 我们的用法不是「一键出谱」，而是**先出草稿，再手动修**：拖腔、同字、气口都要人标。
  这一版还没有自动修谱，见 `docs/LIMITS.md`。

## 装法

1. 按上游 README 装依赖（它有自己的 requirements，别和主环境混）。
2. 权重从上游 release 页下，放到 `models/rosvot/`。
3. 跑一首调性已知的曲子，核对输出的调性与 BPM——**这一步别省**，它在验证权重下对了没有。

## 用法（这一版）

```
python <rospot>/infer.py --input song.wav --output score.json
```

输出进 `voice/scores/`，再用 `whale.py sing` 唱。

## 已知坑

- 长音会被切成几个音：谱出来以后要按听感合并（这一版靠人）。
- 相邻同字（「一滴滴」）会被当成一个拖腔：要么在谱上标成两个字，要么改引擎的切分规则。
- 换气点不会被自动标出来：它不知道人在哪里换气。
