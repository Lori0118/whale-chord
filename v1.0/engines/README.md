# engines：唱这一层的四个引擎

这一层不自己实现模型，只做**接线**：把谱喂进去、把音频接出来、把许可和下载地址写清楚。

| 目录 | 引擎 | 在这套流程里的位置 | 权重 |
|---|---|---|---|
| `rosvot/` | ROSVOT（扒谱） | 音频 → 音符谱，第一步 | 不进仓库 |
| `game/` | GAME + Vocal2Midi | 歌声转换（保留唱法，只换音色）；Vocal2Midi 是另一条扒谱路 | **CC BY-NC-SA，不可商用、不可再分发** |
| `soulx/` | SoulX-Singer | 零样本：参考音色 + 谱 → 直接唱 | 不进仓库 |

DiffSinger 和 RVC 没有单独目录：它们是 `whale.py` 直接调的（`sing` / `convert`），
代码在上游仓库，装法见 `docs/MODELS.md`。

## 为什么 GAME 放在这里但要标红

GAME 的**代码**是 MIT，**权重**是 CC BY-NC-SA。这两条不冲突，但合在一起用就有限制：
不能商用、不能再分发权重。所以它进仓库的是代码和调用脚本，权重自己下，且默认不进主流程。

## 一条通用的接线规矩

引擎脚本（`inference*.py`、`*.ps1`）只做三件事：
读输入路径 → 调模型 → 写输出路径。
**不要在引擎脚本里读全局配置或写死路径**；路径从命令行或 `shared/envs.json` 来。
换机器时只需要改那一处。
