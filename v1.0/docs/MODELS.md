# 模型权重：从哪下、放哪、怎么验

**本仓库不含权重。** 这一页只写「要什么、哪来的、放哪个目录、怎么确认下对了」。

## 目录约定

```
whale-chord/
  models/                    # 全部权重放这里（.gitignore 已排除）
    rosvot/
    diffsinger/
    rvc/
    game/
    soulx/
```

`shared/envs.json` 里只登记解释器；模型路径由各引擎自己的配置或命令行参数给。

## ROSVOT（扒谱）

- 代码：上游仓库，MIT。
- 权重：仓库 release 页或官方文档给的下载地址；注意 release 里对权重的说明可能和代码许可不同。
- 放：`models/rosvot/`
- 验：跑一首已知调性的曲子，看输出的调性与 BPM 对不对（比看文件大小靠谱）。

## DiffSinger（按谱唱）

- 代码：Apache-2.0。
- 声库：**自己训或下**。声库的许可跟着训练数据集走，很多是 CC-BY-NC，不可商用。
- 放：`models/diffsinger/<声库名>/`
- 验：先跑 4 秒、8 个音，看音高误差。我们这一版量到的是**中位 -1 音分**（按谱唱，不换音色）。

## RVC（换声）

- 代码：MIT。
- 权重：自己训。训练集如果不是你自己的声音，权重的分发就要重新想。
- 放：`models/rvc/weights/*.pth` + `logs/<名>/*.index`
- 验：同一句话换声两次，看音色是否稳定（这一版**不稳**，见 `docs/LIMITS.md` 第三条）。

## GAME（歌声转换）

- 代码：MIT。
- 权重：**CC BY-NC-SA**——非商用、相同方式共享。放隔离区，不进主流程。
- 放：`models/game/`
- 验：拿一首已知的歌，看音高走向是否保留。

## SoulX-Singer（零样本）

- 代码：Apache-2.0。
- 权重：官方发布，自己下；训练数据另有条款。
- 放：`models/soulx/`
- 验：给一段参考音色 + 谱，看音高有没有被参考音带跑（我们量到**中位 +9 音分**）。

## 一条通用规矩

下完先做一次**最小验证**：4 秒、一句话、8 个音。跑通了再上整首。
整首歌跑完才发现权重下错了，是最常见的浪费。
