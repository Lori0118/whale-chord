# 契约

三条。改之前先读。

## 1. 音色 = 一个文件

同一段描述、同一个 seed，重跑出来的不是同一条嗓子。所以音色永远是文件（wav / UTAU 音源库 / RVC 权重），不是描述词。

登记在 `shared/voices.json`，每条记录至少要有：`id`、`kind`、`file`、`use`、`status`。
`status` 只有四种：`locked`（验收过）、`candidate`（能用没定）、`experimental`（验证中）、`retired`（路线判死，文件留着）。

## 2. 谱 = 简单形

`sing.py` 吃的是最简单的形状：

```json
[{"midi": 60, "dur": 0.5, "lyric": "wo"}]
```

`whale.py` 会把扩展形（带 `meta`、用 `ch` 代替 `lyric`）摊平后再喂给它。
所以写谱的人可以带标题和原文，引擎只认三件事：音高、时值、字。

**不要**在引擎里加第二套谱格式。要加字段就先加到 `whale.py` 的摊平层。

## 3. 音色层共用，韵律层分家

- 换歌不换嗓子：同一副嗓子唱不同的歌。
- 换嗓子不重写韵律：谱（韵律）和音色是两层。
- 说和唱是同一副嗓子配两种韵律——但**母本要分开**：能说话的腔调不一定唱得好听。

## 4. 测量的分工

- `listen/` 只回答「差在哪」，不回答「好不好听」。
- ASR 是筛查，不是尺子。
- 同一个数在不同工具里口径不同（比如「质心」），**跨表比要先统一口径**，否则差 13 倍。
